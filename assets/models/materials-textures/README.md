# Materials and Textures

Use this folder only for texture files or material resources that come separately from a model export. If a `.glb` already embeds its textures and materials, you do not need to put anything here.

Keep related texture names clear, for example `blackwood_albedo.png`, `blackwood_normal.png`, or `guardian_emission.png`. If you receive a `.gltf` export with separate `.bin` or texture files, preserve the export's relative file structure together so its references do not break.
