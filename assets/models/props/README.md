# Props

Put smaller interactive or decorative objects here: books, potion bottles, chests, candles, desks, shelves, altar pieces, lanterns, signs, and magical objects.

Suggested filenames: `ancient_book.glb`, `sigil_altar.glb`, `magic_lantern.glb`, `treasure_chest.glb`, `floating_crystal.glb`.

Keep separate objects as separate files when you may want to move, animate, or interact with them individually. These assets are staged here until integrated into a Godot scene.
