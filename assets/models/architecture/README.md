# Architecture

Put large buildable structures and architectural pieces here: ruined arches, towers, walls, stairs, bridges, doors, dungeon corridors, sanctuary structures, and building kits.

Suggested filenames: `ruined_arch.glb`, `wizard_tower.glb`, `sanctuary_gate.glb`, `dungeon_corridor.glb`.

For modular pieces, export each piece separately where possible. Keep pivots sensible so pieces can be aligned in Godot. Models in this folder are not automatically placed into a level; they will be integrated into scenes intentionally.
