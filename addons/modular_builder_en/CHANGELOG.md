# Changelog

## 0.2.0

- Add gable walls, gable/shed/pyramid roofs, stairs, fences, and parapets.
- Add plain pillars between vertices or vertically from one vertex with `Alt+click`.
- Add manual vertex creation, movement, removal, merging, and simplified marker display.
- Add wall/gable/pillar centering controls and editable asymmetric dimensions.
- Export a finished structure as one textured mesh in a new scene or as a copy beside the editable structure.
- Include the demo scene and its example textures.
- Split the editor and geometry code into focused scripts.

## 0.1.0 — Initial release

- Create square and triangular foundations, walls, and square or triangular floors directly in the Godot editor.
- Snap pieces together using visible vertices and directional foundation placement controls.
- Split walls at intermediate foundation vertices for separate texturing.
- Add windows, doors, and hatches as openings or separate editable objects.
- Generate general concave collision and save reusable building modules.
