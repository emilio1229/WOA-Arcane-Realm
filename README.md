# WOA: Arcane Realm

A Godot 4 third-person fantasy adventure prototype for The Wizards of Ark.

## Open it
1. Clone this repository with GitHub Desktop.
2. In Godot 4.7 or newer, choose **Import** and select `project.godot`.
3. Press **F6** or **F5** to run the game.

## Current playable foundation
- Start screen and wizard name entry
- Procedurally built purple-lit sanctuary, pillars, and glowing sigil
- Third-person WASD movement, mouse camera, and jumping
- Mathias NPC with a multi-step opening conversation
- Basic objective prompt and story progression

## Controls
- **WASD** — move
- **Mouse** — look around
- **Space** — jump
- **E** — speak to Mathias / continue dialogue
- **Esc** — release mouse capture

This first commit establishes a runnable, asset-free foundation. Replace the primitive placeholder meshes with the project's final art assets as they are added.
