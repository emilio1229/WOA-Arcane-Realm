# Playtest checklist

- [ ] No 3D engine, FBX, or model dependency in runtime.
- [ ] Character creation supports name and male/female options.
- [ ] Class selection shows real approved art, not circles or primitive shapes.
- [ ] Player sprite animation is crisp and consistent.
- [ ] Mathias encounter and opening dialogue work.
- [ ] Spell effects render as real sprites.
- [ ] Touch controls work on iPhone in portrait and landscape.
- [ ] Desktop keyboard controls work.
- [ ] No broken/missing asset requests in browser console.
- [ ] Web build completes and deployed build is smoke-tested.
